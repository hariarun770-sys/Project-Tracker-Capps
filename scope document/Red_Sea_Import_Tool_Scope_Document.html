Detailed Journey
1 Upload & Validate
User does
Uploads required timeslot import files.
System does
Checks file format, required columns, missing data, duplicates, and master-data matching.
Output
Validation pass to continue, or downloadable error report.
2 Import
User does
Confirms the validated upload and starts import.
System does
Loads valid records into the database, logs results, and tracks failures.
Output
Import confirmation, import summary, and downloadable report.
3 Template Generate
User does
Selects month, year, and brand.
System does
Builds a formatted Excel template from imported data.
Output
Downloadable Excel template.
4 Excel Validator
User does
Uploads the generated or updated Excel file for checking.
System does
Validates completeness, formatting, business rules, and booking-related data.
Output
Validation result and downloadable validation report.
5 Bookable Tester
User does
Runs a booking readiness test.
System does
Creates, patches, and deletes a test booking to verify end-to-end usability.
Output
Pass/fail result and test log.
