1. Overview
Module Knowledge Base
Governance Hub route /admin/support/kb
Mirrored route outside /support/kb
Audience Product Owners, Business Analysts, Project Managers, QA Leads, Stakeholders
Purpose Reusable article library for support answers, including AI-assisted reuse through Concierge
2. Business Purpose
  • Capture repeat support resolutions as reusable knowledge
  • Allow staff to author help articles directly
  • Let Concierge use published knowledge for answering common questions
  • Support Draft vs Published content before exposure
3. Target Users
  • Admin / Governance users with access to the support area
  • No role split inside the module
  • Any user with access can view, create, edit, publish/unpublish, and delete articles
4. Entry & Navigation
  • Accessed from Support Tickets screen via “Knowledge Base” button
  • No dedicated left-sidebar link for Knowledge Base
  • Discoverable mainly through Support Tickets or direct URL
  • Breadcrumb is limited and does not fully show Support > Knowledge Base
5. Core Functional Scope
View all articles
Live keyword search
Create new article
Click-to-edit existing article
Delete article with confirmation
Publish / unpublish article
Promote resolved ticket to KB
Markdown body with live preview
6. Screen / Content Summary
Article list with live count
Search box
Rows show title, tags, excerpt, updated date, delete action
Draft articles visibly flagged
Promoted articles include ticket description + public resolution

7. User Workflows
1 Author directly
  • New article
  • Enter title, body, tags
  • Preview
  • Save
2 Promote ticket
  • Resolved ticket
  • Promote to KB
  • Generated article
  • Publish / use
3 Maintain article
  • Open article
  • Edit / unpublish
  • Delete
8. Business Rules
  • Title and body are mandatory
  • Tags are optional free-text, comma-separated
  • Manual new articles default to Published
  • Promoted articles are created as Published
  • Promote to KB only available for Resolved tickets
  • Promote to KB can be used only once per ticket
  • Internal ticket comments excluded from promoted content
  • Delete requires explicit confirmation and cannot be undone
9. Out of Scope / Not Included
No export
No bulk actions
No categorization tree
No approval workflow
No version history
No file attachments
10. Business Impact
  • Reduces repeated support effort
  • Enables self-service knowledge reuse
  • Supports Concierge strategy
  • Low overhead through one-click promotion
  • Basic content control via Draft / Published
11. Permissions & Access
  • Requires sign-in and administrative / governance access
  • Beyond the main access gate, there is no fine-grained permission model within this module
