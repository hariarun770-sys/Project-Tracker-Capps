Integration Configuration – Business Scope

Business View / Phase 1

What is this project?

A new Integration Configuration module in Optimo that moves integration setup from manual / developer-led configuration to a guided, user-managed process.

Business Objective
Standardize how integrations are created and managed
Reduce dependency on developers for routine setup
Improve visibility, control, and governance of integrations
Enable faster onboarding of external systems
In Scope – Business Capabilities
Integration Management Hub
  • • Central list of configured integrations
  • • Search, filters, and status visibility
  • • Edit, delete, activate, deactivate
Guided Integration Creation
  • • Step-by-step setup wizard
  • • Supports Push, Pull, File, and Document types
  • • Required-field validation before progressing
Destination Setup
  • • Configure external endpoints
  • • Supports HTTP / external HTTP / FTP style destinations
  • • Dynamic forms based on integration type
Field Mapping
  • • Map source data to target payloads
  • • Auto-map matching fields
  • • Manual mapping when needed
Chained Integrations
  • • Create multiple related integrations in one session
  • • Review all configured steps before submission
  • • Submit the chain and return to the list

Key Business Outputs

  • • New Integration Configuration area in the platform
  • • Business-friendly workflow for creating and managing integrations
  • • Centralized administration of integration records
  • • Improved ownership using name, description, and point of contact

Business Benefits

Reduced manual database setup
Lower configuration errors
Faster integration onboarding
Better governance and auditability
More scalable integration model
Better user experience for configuration teams

Out of Scope – Phase 1

  • • Drag-and-drop integration designer
  • • Automated API testing
  • • Mobile app support
  • • Advanced nested / hierarchical payload mapping

Success Measures

  • • Integrations can be created successfully through the front-end
  • • Fewer developer-led manual setup activities
  • • Higher adoption of the guided configuration process
