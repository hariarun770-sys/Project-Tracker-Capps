1. Overview
Module: Venues & Assets
Purpose: Central management hub for physical locations and bookable assets in the OptimoGov Governance Hub.
Audience: Product Owners, Business Analysts, Project Managers, QA Leads, Business Stakeholders
Core concept: Manage venues such as buildings, parks, community centres, stadiums, and the assets within them.
2. Business Purpose
  • Centralized catalog management
  • Pricing control for all bookable spaces and assets
  • Booking readiness via completeness tracking
  • Audit compliance for changes
  • Access control configuration for automated entry venues
  • Terms management with revision history
3. Target Users
  • Governance Administrators: Manage the venue and asset catalog
  • Venue Coordinators: Maintain venue details
  • Pricing Officers: Handle pricing revisions across assets
  • QA / Onboarding Staff: Review setup completeness before go-live
  • System Administrators: Configure access provider integrations
4. Entry & Navigation
  • Governance Hub > Catalog > Venues & Assets
  • Breadcrumb: Governance > Catalog > Venues & Assets
  • Top-right actions: Bulk price revision, + New venue
5. Core Functional Scope
Venue Management
  • View venues in an alphabetically sorted list with category icon and asset count badge
  • Filter by name/suburb, category, suburb, and whether the venue has assets
  • Create a new venue via manual form, URL extraction, bulk import, or AI-assisted prompt
  • Edit venue details across 10 sections: Basics, Media, Hours, Documents, Contact, Directions, Terms, Assets, Access Control, Audit
  • Delete venue with confirmation
  • Toggle Active / Inactive status
  • View venue completeness progress
Asset Management
  • View assets for the selected venue, grouped by type
  • Filter by name, type, category, status, scope, pricing, sub-units, and completeness
  • Add new assets
  • Preview asset details including capacity, configurations, pricing, activities, hours, documents, and audit
  • Open asset editor from preview
  • Expand/collapse asset type groups with saved user preference

7. User Workflows
1
Browse & Manage
  • Open module → Select venue
  • Select asset → Preview
  • Edit → Save
2
Create New Venue
  • Click "+ New venue"
  • Choose Manual / AI / Bulk
  • Complete 10 tabs → Save
  • Venue appears in list
3
Apply Bulk Pricing
  • Open bulk price revision
  • Select assets → Enter price & effective date
  • Preview → Confirm
4
Filter Venues
  • Open filter → Search / choose category or suburb
  • Done → Filtered list
8. Business Rules & Validation
  • Venue name, suburb, address, description are required
  • Slug is required, unique, and uses lowercase letters, numbers, hyphens
  • Slug auto-generates from name until manually edited
  • If entry mode is Keypad or Self-access, an access provider is required
  • Inactive venues/assets remain in system but hidden from public portal
  • Delete requires confirmation
  • Terms revisions are versioned
  • Every asset belongs to exactly one venue
9. States & Messages
  • Initial load shows "All venues" mode
  • No venue selected: "Select a venue to get started"
  • Filter with no results shows empty list
  • Save in progress shows "Saving..."
  • Successful save shows a toast notification
