1. Functional Scope & AI Capabilities
  • Natural Language Slot Discovery: Citizens type conversational queries (e.g., "Find an open track session at Marina Bay next Tuesday for 2 cars") and receive structured recommendations.
  • Rich-Media Card Responses: Returns interactive space cards with live capacity badges, session timestamps, and a 1-click "Add to Reservation" action button.
  • Cross-Selling & Equipment Add-ons: Proactively suggests related assets (e.g., BMW M2 fleet hire, Paddock Club VIP passes, or Car Park North bays).
  • Seamless Ticket Escalation: When an inquiry cannot be automated, user clicks "Escalate to Support" to pre-populate the Support Ticket dialog with full chat context.
2. Citizen Interaction User Journey
Journey Step Citizen Action AskOptimo Response
1. Initiate Clicks AskOptimo icon / presses ⌘I Drawer slides in with contextual prompt chips
2. Inquire Types request for date & venue Verifies live diary slots & returns rich cards
3. Select Clicks "Add to Reservation" card Directly updates booking cart in background
4. Complete Reviews itemized summary Navigates citizen to checkout folio
Context Awareness:
AskOptimo automatically knows the active route (e.g. /venues/marina-bay-autodrome) and focuses answers on that venue without asking the user to re-specify location.
